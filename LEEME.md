# Cydno Guides — actualizaciones

Este repositorio sirve, mediante GitHub Pages, las actualizaciones de **Cydno Guides**, la extensión de Adobe Illustrator
de Cydno para construir y presentar logotipos. Solo lo consultan las copias ya instaladas para saber si hay una
versión nueva y descargarla.

- Contiene el manifiesto de actualizaciones firmado (`estable/latest.json` y su firma), los paquetes firmados de cada
  versión (`paquetes/`) y sus notas (`notas/`). No contiene código fuente ni instaladores.
- Cydno Guides es **software privado de Cydno, en fase de prueba**: solo pueden usarlo las personas a las que Cydno se
  lo entrega o invita. Que estos archivos sean accesibles no concede ningún derecho de uso. Consulta la
  [licencia](LICENCIA.txt).

Adobe e Illustrator son marcas registradas de Adobe. Cydno Guides no está afiliado a Adobe.
